## The App

Interactive influence map and teaching tool. Built with Next.js + TypeScript + Tailwind CSS.

```bash
npm install
npm run dev    # http://localhost:3000
```

## Where this sits

This repo pairs fourteen short essays on chess tempo, tension and board vision with a Next.js and TypeScript app that draws influence zones and runs a look-ahead computer opponent. Born in Era 2 on February 10, 2026, from his earlier private work, its app landed by February 26 and its 25th commit on June 29, 2026, later feeding the Book.

Chimera was a personal art, code and learning project: its laws and physics are story or browser simulation, and its scores, rungs and records are our own measures. This README already frames the repo as a teaching tool and lens on the game, and labels like "DNA" in the folder tree are metaphors for shared notes.

The work is complete as of October 2026 and stays open to anyone who wants to continue it; the Book at https://reemifai.org/book is the main way in.
